-  Invadimos um banco e depositamos dinheiro usando o comando `dirb` → `dirb` is a command-line web content scanner used in penetration testing to find hidden files and directories on web servers by launching a dictionary-based attack. 
		
	Usando o comando: 
	
	`dirb <url_base>` ele faz descoberta de conteudos (content discovery). Ele pega uma lista enorme de nomes comuns (admin, backup, etc) e testa um por um no web server para ver as paginas/pastas que existem mas não estão listadas em lugar nenhum. Força bruta. O `dirb` prova que o “escondido” ≠ “seguro”.

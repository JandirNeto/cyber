#### Identificando dispositivos na rede

**Um humano possui:**

Nome e Digital 

**Um Dispositivo:** 

Endereço IP
Media Access Control (MAC)

IPV4 - Usa números de 32 bits divididos em quatro blocos decimais, permitindo cerca de 4,3bi de endereços unicos. Cada Bloco tem 8 bits.

IPV6 - A principal mudança está no tamanho, já que utiliza 126 bits, em vez de usar números decimais separados por pontos, o IPV6 utiliza números hexadecimais (Letras de `a` até `f` e números de `0`  a  `9`) separados por dois pontos ( : )

IPV4 - 192.168.1.1
IPV6 - 2001:0db8:85a3:0000:0000:8a2e:0370:7334 - Possui 8 blocos de 16 bits cada.

Um IP publico é diferente de um IP privado

ISP - Internet Service Provider

Gateway - é um dispositivo ou sistema que conecta uma rede de computadores a outra, ou um sistema a outro.

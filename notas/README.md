# notas

Anotações das sessões de estudo, uma por arquivo, em markdown.

Nome do arquivo: `AAAA-MM-DD-titulo.md` (é o que o botão *Baixar .md* já gera).

Regra 6 do plano: **últimos 10 minutos de toda sessão, cinco linhas.** Sem capricho.
O objetivo não é escrever bem — é fixar o conteúdo, alimentar o gráfico de commits e
acumular portfólio sem esforço extra.

Modelo:

```markdown
# Assunto da sessão

> 12/08/2026 (seg) · #redes #dns

1. O que eu estudei hoje
2. O que finalmente fez sentido
3. O que continuou confuso
4. Comando/ferramenta nova que usei
5. Onde eu paro amanhã
```
